An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 (1 Platinum, 2 Gold, 6 Silver, 46 Bronze; 28 hidden; 0 online). Every trophy shows its official name, description and grade exactly as PlayStation publishes them, plus an original guide in our own words that cites its sources. The tracker saves progress in the browser (localStorage), exports and imports the checklist as JSON, filters by grade, kind, missable and earned state, and has a spoiler setting that hides story trophies until they are earned. A six-stage roadmap leads to the platinum, and the one missable trophy — Positive Mental Attitude, whose first meditation can be lost after Chapter 1 — is flagged throughout.

Names, descriptions, grades and PSN progress targets were verified on 2026-11-19 against Exophase and PSNProfiles (the two agree on every entry), with Press-Start as a third check. Where a launch-day trigger is still unconfirmed, the guide says so instead of guessing.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is static files under `app/` and works with the network off.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
